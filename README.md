## ✦ The Architecture

This project was built under strict performance and architectural constraints to ensure lighting-fast load times, seamless mobile responsiveness, and zero reliance on third-party bloat.

### Tech Stack
- **HTML5:** Semantic, accessible structure.
- **CSS3:** Advanced Grid/Flexbox layouts, custom animations, variables for consistent monochromatic theming, and responsive media queries.
- **Vanilla JavaScript:** Native DOM manipulation, IntersectionObserver API for scroll animations, and optimized requestAnimationFrame loops.
- **Zero Dependencies:** No React, No Tailwind, No GSAP, No Three.js. 

### Core Features
- **Single-File Delivery:** All structure, styling, and logic are contained within a single, highly optimized `index.html` file.
- **Premium Aesthetic:** Deep blacks, bright white typography, structural 1px grid lines, and deliberate negative space inspired by luxury digital agencies.
- **Custom Magnetic Cursor:** A smooth-trailing custom cursor that adapts to interactive elements.
- **IntersectionObserver Animations:** Elements gracefully fade and slide into view as the user scrolls down the page.
- **The Arsenal Grid:** A meticulously structured section detailing technical proficiencies across Motion, Web Architecture, Market Tech, and Audio Synthesis.
- **Infinite Workflow Reel:** A continuous, auto-scrolling marquee showcasing visual assets, which pauses on user interaction.
- **Immersive Footer:** A striking bottom section featuring an oversized, outlined typography watermark and structured legal/social routing.

## ✦ Quick Start

Because this project is built entirely without build steps or external dependencies, running it is incredibly simple.

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Double-click the file to open it in your preferred modern web browser (Chrome, Edge, Safari, Firefox).
4. *Optional:* To test local network features or avoid strict CORS issues on some browsers, serve the file using a simple local server (e.g., VS Code Live Server, or Python's `python -m http.server`).

## ✦ Project Structure Overview

Inside the single `index.html`, the code is organized into three distinct layers:
1. **`<style>` block:** Contains all CSS reset rules, typography definitions, grid layouts, animations, and media queries.
2. **`<body>` tags:** Contains the semantic HTML structure (Navbar, Hero, Services/Arsenal Grid, Workflow Reel, Project Showcase, CTA, Footer).
3. **`<script>` block:** Contains all JavaScript logic grouped by functionality (Cursor tracking, Scroll Observers, Marquee logic, Modal interactions).
